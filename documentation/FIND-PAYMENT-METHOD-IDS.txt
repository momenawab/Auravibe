═══════════════════════════════════════════════════════════════

📍 STEP 1: Log in to Paymob Dashboard
   → https://accept.paymob.com/portal2/en/login

═══════════════════════════════════════════════════════════════

📍 STEP 2: Navigate to Payment Integrations

   Left Sidebar:
   ┌─────────────────────┐
   │  Dashboard          │
   │  Transactions       │
   │  Orders             │
   │  ▼ Developers       │  ← Click this
   │    ├ API Keys        │
   │    ├ Webhooks        │
   │    ├ Integrations    │  ← Then click this
   │    └ iFrames         │
   │  Settings            │
   └─────────────────────┘

═══════════════════════════════════════════════════════════════

📍 STEP 3: Find Your Payment Integration IDs

   You'll see a list like this:

   **IMPORTANT**: These are YOUR integration IDs (not payment method IDs!)

═══════════════════════════════════════════════════════════════

📝 WHAT TO DO:

The Unified Checkout API uses Integration IDs directly, not payment method IDs!

Copy YOUR integration IDs and update your .env file:

```env
# In /home/believer/auravibe/.env

# Update these with YOUR actual Integration IDs from dashboard:
PAYMOB_INTEGRATION_ONLINE_CARD=5362354    ← Replace with YOUR Card ID
PAYMOB_INTEGRATION_MOBILE_WALLET=5362355  ← Replace with YOUR Wallet ID
```

═══════════════════════════════════════════════════════════════

🔧 IMPORTANT NOTE:

The Unified Checkout API works differently:
- OLD API: Used Integration IDs in backend
- NEW API: Uses Integration IDs as "payment_methods" in the request

Your Integration IDs ARE the payment method IDs for Unified Checkout!

═══════════════════════════════════════════════════════════════
